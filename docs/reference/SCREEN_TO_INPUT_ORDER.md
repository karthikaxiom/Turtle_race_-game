# Screen to Input Order

The current program establishes the graphics screen before requesting the race input.

1. Create the turtle screen with `turtle.Screen()`.
2. Configure its dimensions and title.
3. Display the text-input dialog.
4. Store the returned value as `user_bet`.
5. Continue into turtle creation.

The documentation reflects the existing order in `main.py` and does not introduce a separate input or UI layer.

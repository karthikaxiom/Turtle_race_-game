# Runtime Dependencies

The game relies on Python's standard library only.

## Python modules

- `turtle` provides the graphical turtle objects, screen, input dialog, and window lifecycle.
- `random` provides the per-turn movement distance.

## Platform requirement

The `turtle` module requires a working Tk-based graphical environment. A headless terminal alone is not sufficient to display the race window.

No third-party Python package is imported by `main.py`, so there is no project-specific package installation step.
